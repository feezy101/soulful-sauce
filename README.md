# Just Feezy Soulful Sauce

A chord progression generator plugin for soulful house, deep house, neo-soul, gospel, jazzy lounge and Afro soul.
VST3, Audio Unit and a standalone app, built with [JUCE 8](https://juce.com).

- Pick a **Key**, **Style** and **Mood** (Balanced, Mellow, Happy), then **Re-roll** for new progressions.
  The arrows beside Re-roll step back and forward through the last 50.
- **Bars**, **Chord length** and **Voicing** (Close, Drop 2, Wide) set the shape; **Octave** moves it up or down.
- Knobs: **Richness** (7ths, 9ths, lush 11ths/13ths), **Spice** (substitutions and turnarounds),
  **Humanize**, **Velocity**, **Strum**.
- **Rhythm**: Pads, Pushed (anticipated), House stabs, Offbeat organ.
- Built-in **Sound** (Rhodes, Pad, Piano, Organ or Off), **MIDI out**, and **Drag MIDI** into FL Studio.
- Lock chords to keep them through re-rolls. Everything is saved with your FL project.

## How it's built

```
source/engine/      Chord engine and pattern baker. Pure C++, no JUCE.
                    A line-for-line port of reference/Soulful Chords.pyscript.
source/             Plugin: parameters, processor (host sync, MIDI, history, state), synth, editor.
source/ui/          Look and feel, widgets, chord cards, keyboard.
tests/              Engine parity test (4,000 cases generated by the FL script) and a plugin smoke test.
packaging/          Installer script and read-me shipped with the Mac build.
.github/workflows/  Cloud build for macOS: universal VST3 + AU + Standalone, zipped.
```

The engine must keep producing exactly what the FL script produces. `EngineParityTest` checks this on every build.
Floating point contraction is switched off for the engine (`-ffp-contract=off`) so results are identical on Apple Silicon.

## Building

**Cloud (recommended):** push to `main` on GitHub. The *Build Soulful Sauce* workflow builds on macOS and
uploads `Soulful-Sauce-mac.zip` as a build artifact (Actions tab → latest run → Artifacts).
Push a tag like `v0.1.0` to also publish it as a GitHub Release.

**On a Mac with Xcode:**

```sh
cmake -S . -B build -G Xcode
cmake --build build --config Release
```

**Linux / quick checks:**

```sh
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/EngineParityTest tests/reference_cases.txt
```

Add `-DSAUCE_SMOKE_TEST=ON` to build `PluginSmokeTest`, which runs the real processor without a DAW,
checks MIDI timing, history, locks and state, renders audio demos and a picture of the window.

## Notes

- **FL Studio and MIDI out:** routing a VST3's MIDI output to another channel is unreliable in FL Studio,
  so the plugin makes its own sound and offers Drag MIDI. MIDI out is still sent for hosts that use it.
- **Signing:** builds are ad-hoc signed. Distributing to other Macs without Gatekeeper warnings needs an
  Apple Developer ID ($99/year) for signing and notarization.
- **Licences:** JUCE is used under its licence (free Starter tier below $20k annual revenue).
  Manrope and JetBrains Mono fonts are under the SIL Open Font License (see `resources/fonts`).
